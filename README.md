Website for **Volley Club Nogentais**, built with the [Hugo](https://gohugo.io/) static site framework. Live at
<https://volley-club-nogent.fr/>.

## Stack

- **[Hugo](https://gohugo.io/)** - static site generator (templates in `layouts/`, content in `content/`).
- **[Bootstrap 5](https://getbootstrap.com/)** - CSS framework, imported via SCSS (`assets/sass/main.scss`) with the JS
  bundle loaded from a CDN.
- **[Font Awesome 7](https://fontawesome.com/)** - icon set, loaded from a CDN and used via the `fontawesome` shortcode.
- **[Swiper 11](https://swiperjs.com/)** - carousel/slider, loaded from a CDN, used for the teams list.
- **[Decap CMS](https://decapcms.org/)** (formerly Netlify CMS) - content-editing UI at `/admin`, GitHub backend with an
  editorial workflow (one PR per entry).
- **Python** (stdlib only) - scripts that fetch and merge match calendars.

## Getting started

Local dev runs through Docker Compose:

```bash
docker compose up
```

The site is then served at <http://localhost:1313/> (drafts and future-dated content included).

Alternatively, with Hugo installed locally (extended version, >= 0.99.1):

```bash
hugo server --buildDrafts --buildFuture
```

Node dependencies (formatting tooling + Bootstrap sources) are installed with:

```bash
npm ci
```

## Project structure

- `content/` - Markdown pages and articles (French).
- `layouts/` - Hugo templates.
- `assets/` - SCSS, JS and media sources.
- `config/_default/` - Hugo configuration.
- `data/calendars/` - match calendars, generated by the scripts below, do not hand-edit.
- `scripts/` - Python scripts fetching and merging match calendars from the FFVB and FSGT federations.
- `static/admin/` - Decap CMS configuration.
- `public/` - Hugo build output, generated.

See [AGENTS.md](AGENTS.md) for detailed conventions, tooling, and CI/CD documentation.

## Formatting

Formatting is enforced via pre-commit (EditorConfig, Prettier, yamlfmt, codespell):

```bash
pre-commit run --all-files
```

## Deployment

- Pushes to `feat/**` or `fix/**` branches build and deploy a preview to GitHub Pages.
- Pushes to `main`, and a daily cron job (7:15 AM UTC), build and deploy to production via `rsync`.
