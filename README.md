Website for **Volley Club Nogentais**, built with the [Hugo](https://gohugo.io/) static site framework. Live at
<https://volley-club-nogent.fr/>.

## Stack

- **[Hugo](https://gohugo.io/)** - static site generator (templates in `layouts/`, content in `content/`).
- **[Tailwind CSS v4](https://tailwindcss.com/)** - CSS framework, CSS-first config (`assets/css/main.css`), built by
  Hugo's native `css.TailwindCSS` pipe (no separate build step, no CDN).
- Self-hosted SVG icons (`assets/icons/`, originally sourced from Font Awesome Free) rendered via the `fontawesome`
  shortcode - no CDN or icon-font dependency.
- **[Swiper 11](https://swiperjs.com/)** - carousel/slider, self-hosted (`assets/js/vendor/`, `assets/css/vendor/`),
  used for the teams list and photo galleries.
- **[Sveltia CMS](https://github.com/sveltia/sveltia-cms)** - content-editing UI at `/admin`, a drop-in replacement for
  Decap CMS (formerly Netlify CMS), GitHub backend with an editorial workflow (one PR per entry).
- **Python** (stdlib only) - scripts that fetch and merge match calendars.

## Getting started

Local dev runs through Docker Compose:

```bash
docker compose up
```

The site is then served at <http://localhost:1313/> (drafts and future-dated content included).

Alternatively, with Hugo installed locally (extended version, >= 0.99.1):

```bash
hugo server --buildDrafts --buildFuture
```

Node dependencies (formatting tooling + the Tailwind CSS build) are installed with:

```bash
npm ci
```

## Project structure

- `content/` - Markdown pages and articles (French).
- `layouts/` - Hugo templates.
- `assets/` - CSS, JS and media sources.
- `config/_default/` - Hugo configuration.
- `data/calendars/` - match calendars, generated by the scripts below, do not hand-edit.
- `scripts/` - Python scripts fetching and merging match calendars from the FFVB and FSGT federations.
- `static/admin/` - Sveltia CMS configuration.
- `public/` - Hugo build output, generated.

See [AGENTS.md](AGENTS.md) for detailed conventions, tooling, and CI/CD documentation, and [docs/](docs/) for guides on
editing content and site configuration:

- [docs/editing-pages.md](docs/editing-pages.md) - how to manage and edit all site pages through `/admin`.
- [docs/monthly-logo.md](docs/monthly-logo.md) - how the top-left logo changes depending on the month, and how to change
  it.
- [docs/gyms.md](docs/gyms.md) - how to add a new gym for team training sessions.

## Formatting

Formatting is enforced via pre-commit (EditorConfig, Prettier, yamlfmt, codespell):

```bash
pre-commit run --all-files
```

## Deployment

- Pushes to `feat/**` or `fix/**` branches build and deploy a preview to GitHub Pages.
- Pushes to `main`, and a daily cron job (7:15 AM UTC), build and deploy to production via `rsync`.
