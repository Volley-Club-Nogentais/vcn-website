{{- $resource := .resource -}} {{- $alt := .alt | default "" -}} {{- $class := .class | default "" -}} {{- $style := .style | default slice -}} {{- $fill := .fill -}} {{- $resize := .resize -}} {{- $width := .width -}} {{- $height := .height -}} {{- $zoomable := .zoomable | default false -}} {{- $loading := .loading | default "lazy" -}} {{- $img := $resource -}} {{- $classes := slice -}} {{- with $class -}} {{- $classes = $classes | append . -}} {{- end -}} {{- /* fill crops to an exact box; resize only caps a dimension, keeping the resource's aspect ratio. */ -}} {{- $processed := "" -}} {{- with $fill -}} {{- $img = $resource.Fill . -}} {{- $processed = . -}} {{- end -}} {{- with $resize -}} {{- $img = $resource.Resize . -}} {{- $processed = . -}} {{- end -}} {{- with $processed -}} {{- $dominant := "var(--color-vcn-blue)" -}} {{- with $resource.Colors -}} {{- $dominant = index . 0 -}} {{- end -}} {{- $style = $style | append (printf "background-color:%s" $dominant) -}} {{- $classes = $classes | append "blur-up" -}} {{- end -}} {{- if $zoomable -}} {{- $classes = $classes | append "zoomable" -}} {{- end -}} {{- /* Vector resources (SVG) don't support .Width/.Height at all (calling them errors out), so only fall back to the resource's own metadata for raster images. */ -}} {{- $isRaster := ne $img.MediaType.SubType "svg+xml" -}} {{- $imgWidth := $width -}} {{- $imgHeight := $height -}} {{- if and (not $imgWidth) $isRaster -}} {{- $imgWidth = $img.Width -}} {{- end -}} {{- if and (not $imgHeight) $isRaster -}} {{- $imgHeight = $img.Height -}} {{- end -}}
